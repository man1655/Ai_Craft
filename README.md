# 🚀 Resume Builder & Interview Prep App

An all-in-one platform to create professional resumes, analyze them against job descriptions, and prepare for interviews with intelligent question suggestions.

## 🧰 Tech Stack

- **Frontend:** React + Vite + TailwindCSS
- **Backend:** Node.js + Express
- **Database:** MongoDB (via Mongoose)
- **Resume Analysis Engine:** Python (Flask or FastAPI) + Sent
---

## ✨ Features

### 📝 Resume Builder
- Live preview resume editor
- Download resume as PDF
- Multiple templates

### 📊 Resume Analyzer
- Upload resume & job description
- Match score using AI
- Highlights missing skills and suggestions

### 🎯 Interview Preparation
- AI-generated questions by job role or skills
- Practice interface with answer hints
- Save/bookmark questions

### 🔐 User Authentication
- Signup/Login with JWT
- Email verification via OTP
- Forgot password with OTP reset
